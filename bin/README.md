# cs2_aim — external overlay

Готовый exe: `bin\cs2_aim.exe`. Рядом с ним должен лежать `offsets.ini` — положи их в одну папку.

## Запуск

1. Запусти CS2, зайди в матч (окно игры должно быть в режиме **borderless/windowed** — в чистом fullscreen оверлей не отрисуется).
2. Запусти `cs2_aim.exe` (можно после захода в матч — чит сам найдёт процесс).
3. **Insert** — открыть/закрыть меню. Когда меню открыто, мышь работает в меню; когда закрыто — клики проходят в игру.
4. **Зажать Mouse5** (боковая кнопка мыши) — аимбот ведёт на голову ближайшего врага в FOV.
5. Закрытие: открой меню (Insert) и закрой окно меню крестиком, либо просто убей процесс.

## Меню

- aim assist — аимбот вкл/выкл (по умолчанию вкл)
- vision — ESP вкл/выкл (по умолчанию вкл)
- fov — радиус захвата цели в градусах, 1–30 (по умолчанию 8)
- smooth — плавность наводки, 1 = мгновенно, 20 = очень мягко (по умолчанию 8)

## ESP

- 2D-бокс по каждому видимому в кадре врагу
- полоска здоровья слева от бокса (зелёная → красная)
- дистанция в метрах под боксом
- союзники и мёртвые не рисуются, dormant-энтити пропускаются

## Обновление оффсетов

Все оффсеты — в `offsets.ini` рядом с exe. После обновления игры отредактируй значения (hex с `0x` или десятичные), перезапусти чит. Свежие дампы: https://github.com/sezzyaep/CS2-OFFSETS (файлы `offsets.cs` + `client_dll.json`, dw-оффсеты из первого, поля классов из второго).

Формат: `dwEntityList=0x271FBB8` и т.д. Список ключей совпадает с именами полей в ini.

## VAC-статус

- Чит полностью внешний: только ReadProcessMemory + запись 12 байт углов обзора при зажатом Mouse5. Инжекта, хуков, драйверов нет.
- Ничего не пишет на диск во время работы, не ходит в сеть, логов нет.
- Отключается от захвата OBS/Game Capture (WDA_EXCLUDEFROMCAPTURE) — стрим его не увидит.
- Оверлей — обычное topmost-окно с colorkey-прозрачностью.
- **Гарантий нет и быть не может**: VAC — серверная система, бан может прилететь с задержкой. Внешние RPM-читы — самый живучий класс, но запускаешь на свой риск. Рекомендации: переименуй exe во что-нибудь нейтральное, не свети им в стримах/на скринах, не держи включённым в меню без дела.
- Аимбот пишет углы обзора — это самый заметный для VAC компонент. ESP-only режим (aim assist выкл) вообще ничего не пишет в память игры.

## Если что-то отвалилось после обновления игры

Симптомы: меню открывается, но боксов нет / аим не ведёт.
Причина: Valve сдвинули оффсеты. Возьми свежий дамп по ссылке выше и обнови `offsets.ini`. Если сдвинули структуру энтити-листа — правь `entityChunksOffset` / `entityIdentityStride` там же.

## Сборка из исходников (не требуется для использования)

`build.bat` — release, `build.bat dbg` — консольный вариант с отладочным выводом. Требует MSVC x64.
